## Project Description

Remember the days when a phone had buttons, Snake was the most advanced game you had, and the only goal in life was to make that snake as long as possible?

**Snake Game** brings back the classic Nokia Snake experience in a simple browser-based game built with HTML, CSS, and JavaScript.

No AI.
No multiplayer.
No blockchain.
No reason to play it.

Just **Snake.** 🐍

---

## The Problem (that doesn't exist)

Modern games have become unnecessarily complicated.

Open-world maps.
Battle passes.
Ultra-realistic graphics.
100 GB downloads.
Microtransactions.

We identified a serious problem:

> **Where did the simple Snake game go?**

Students today are suffering from an extreme lack of unnecessary nostalgia.

---

## The Solution (that nobody asked for)

We brought back the most technologically advanced game of the early mobile-phone era:

### 🐍 SNAKE.

Control a tiny snake.

Eat food.

Get longer.

Don't hit the wall.

Don't hit yourself.

Repeat until you inevitably ruin everything.

That's it.

# Features

### 🐍 Classic Snake Gameplay

Control the snake and navigate around the game board.

### ⌨️ Keyboard Controls

Use the arrow keys to control the snake:

```text
       ↑
   ←   ↓   →
```

### 🍎 Random Food

Food appears at random locations on the game board.

### 📈 Growing Snake

Every time the snake eats food, it grows longer.

### 💀 Collision Detection

The game ends when the snake:

* Hits the wall
* Hits itself

### 🏆 Score

The player's score increases as they eat more food and grow the snake.

### 🔄 Restart

Lost?

Just start again.

Because apparently we haven't learned our lesson.
